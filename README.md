#  Responsive Sidebar Menu (HTML & CSS)

This project is a responsive sidebar menu built using HTML and CSS only.
The sidebar opens and closes using a hamburger menu icon without using JavaScript.
A CSS checkbox is used to control the sidebar animation.

This mini project helped me practice CSS positioning, transitions, hover effects,
and responsive layouts.

---

##  Features
- Hamburger menu button
- Sliding sidebar animation
- Close button inside sidebar
- Font Awesome icons
- Hover effects on menu items
- Fully responsive layout
- No JavaScript used

---

##  Technologies Used
- HTML5
- CSS3
- Google Fonts
- Font Awesome Icons
